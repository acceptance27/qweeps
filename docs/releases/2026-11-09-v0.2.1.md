# QWEEPS v0.2.1 — Ordered Recall and Adaptive Quiz Challenges

This release adds ordered multi-blank questions, scored recall challenges, application
themes, and an updated standalone Android installer.

## Quiz changes

- **Ordered recall:** related lists and multi-part facts use 2–5 numbered blanks
  with a shared bank of 8–10 short choices. Fill the sentence from left to right.
- **Each blank counts:** each blank is independently graded and counts toward
  challenge points, streaks, heart recovery and recall scheduling.
- **Automatic advancement:** correct answers advance to the next blank in the
  sentence. Placed answers darken, display a checkmark and “Placed”, and stay disabled.
- **All Questions challenges:** difficulty-weighted points, streak multipliers,
  personal bests and five hearts. A wrong answer costs one heart; every five correct
  answers restore half a heart, up to five. Zero hearts ends the run with retry
  and practice available.
- **Adaptive recall:** repeated misses return sooner. Clean recalls stretch the
  interval toward ten other answers. Later returns of a successfully answered
  recurring question require typing without choices.
- **Saved challenges:** pause/resume and device-local progress persistence, with
  practice sets kept separately. Live mastery boxes and numeric progress counters
  are removed.
- **Fresh, source-grounded generation:** selected PDF, Word (.docx) and PowerPoint
  sources produce a separately saved quiz with source locations and supporting
  evidence, rather than silently reopening an older quiz.

## Appearance and desktop architecture

Settings → Appearance offers Pixel Forest, Architecture, Midnight and Amethyst.
The desktop architecture preview adds shared OpenCode Go settings, recorded voice
explanation and synchronized packet playback. Architecture remains an incomplete,
experimental feature and requires the desktop Node.js backend.

## Android download and installation

Download **QWEEPS-0.2.1.apk** from the assets below. Package `org.qweeps.app`,
version name **0.2.1**, version code **3**; ARM64 phones and x86_64 emulators;
minimum Android 8.0 (API 26), including Android 11.

The APK bundles the React studio and Python 3.11 runtime. It includes Visual Lessons
and Quizzes. **The architecture workspace does not work independently on Android**;
its Node.js backend is not included in the standalone app.

This direct-install APK uses the same local Android debug signing certificate as
previous installers. Install it over the existing app to retain app-private data.
It is not a Play Store-signed release. API credentials and personal lesson libraries
are not shipped in the APK. Use Quiz Export/Import to move an existing desktop
quiz to Android.

`QWEEPS-0.2.1.apk.sha256` provides the installer checksum. On a system with sha256sum:

```bash
sha256sum -c QWEEPS-0.2.1.apk.sha256
```

## Verification

The feature update passed 647 Python tests (2 skipped), 168 frontend tests, host and
architecture TypeScript checks, and a production web build. Android packaging,
manifest version, bundled frontend/Python modules, and signing certificate were
checked. The ordered interface was reviewed in portrait and landscape in the browser.
No new physical-device or Android-emulator test was run for this release.

Build from source with `npm run android:build`; setup and runtime limits are
in [docs/android.md](https://github.com/acceptance27/qweeps/blob/v0.2.1/docs/android.md).
The technical report PDF remains the separately versioned 2.1 research snapshot
from before the latest quiz and architecture-voice implementation.
