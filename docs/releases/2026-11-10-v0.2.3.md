# QWEEPS v0.2.3 — Quiz Tutor & Fish Voice

Ask QWEEPS in the reinforcement quiz now responds to the learner's actual message,
including greetings and follow-up questions. A failed model request displays an
error instead of repeating the stored card explanation as a substitute answer.

## Changes

- Quiz chat uses the current question, available source evidence, and conversation
  history. Imported quiz banks can be discussed even when their original PDF is
  absent on the phone. The default Ask model is OpenCode Go Muse Spark 1.3 Contributor.
- Text chat becomes available as soon as the answer arrives, while optional speech
  prepares independently. Starting another question or stopping speech cancels
  pending audio so an old reply cannot begin later.
- Android now retains Fish Audio as its selected provider instead of disabling it
  at startup. Fresh setups default to direct Fish Audio, model `s2.1-pro-free`,
  voice `278d128593e44753a522dd52a5a63645` — the current desktop voice. Ask replies
  inherit the lesson voice unless separately configured.
- Settings/APIs includes a Fish Audio API key field. Add your own key on the phone;
  personal credentials are not included in the APK. Existing saved provider and
  voice preferences remain intact on upgrade.
- Quiz-generation instructions use English while preserving actual names and
  titles. New-format quiz banks use regular sets rather than the older curated
  Morga-only unit grouping.
- The previous 32 MiB JSON import limit and whole-card ordered recall fixes remain.

## Install

Download **QWEEPS-0.2.3.apk** and install it over the existing app to retain its
app-private data. Package `org.qweeps.app`, version code **5**, Android **8.0+**
(API 26), ARM64 phones and x86_64 emulators. Android 11 meets the minimum version.
The APK uses the same local Android debug signing certificate as earlier
QWEEPS direct-install releases; this is not a Play Store release.

The APK includes Visual Lessons, Quizzes, and bundled Python. The architecture
workspace still requires the desktop Node.js backend and does not operate
independently on Android. In-progress Knowledge Flow work is excluded from this
maintenance release.
