# QWEEPS v0.2.2 — Large Quiz Imports

This update fixes large quiz/lesson JSON imports in the standalone Android app.

## Quiz fixes

- **Larger imports:** Import JSON now accepts requests up to **32 MiB
  (33,554,432 bytes)**. Previously, imports shared the 250 KB limit used for small
  control requests. Large banks retain their questions, explanations, and ordered
  blanks; importing does not regenerate or trim the bank.
- **Readable size errors:** oversized imports report the limit in MiB and bytes.
- **Whole-card ordered recall:** a numbered multi-blank sentence counts as one
  card. After completing all blanks, any mistake repeats the entire card until a
  mistake-free pass. Points, streaks, hearts, and recall scheduling apply once per
  completed card rather than separately for each blank.

## Android installation

Download **QWEEPS-0.2.2.apk** below and install it over the existing QWEEPS app to
retain app-private data. Package **org.qweeps.app**, version **0.2.2**, version code
**4**. Supports ARM64 phones and x86_64 emulators on Android 8.0+ (API 26), including
Android 11. The installer uses the same local Android debug signing certificate as
the previous direct-install releases; this is not a Play Store release.

The APK includes Visual Lessons, Quizzes, and the bundled Python runtime. The
architecture workspace still requires the desktop Node.js backend and does not
work independently on Android. The in-progress Knowledge Flow integration is not
included in this maintenance APK.

The limit applies to the serialized JSON request sent to the server. Changing
desktop source files does not update an installed APK; install this update to get
the fix on your phone. Existing exported quiz JSON files can be imported again.
