## Decision

The file `Chapter-2-Entrepreneurs-and-Entrepreneurial-Competencies_9cff2dee.pdf` has been excluded from both
`visual-studio/public/assets/aistudio/` and its prebuilt `dist/` counterpart.
Its SHA-256 is `9cff2dee86980d32f7445a94f0e803ca235636864efd24f2b48e37c5da548613`.

The supplied document has 53 pages and includes SlidesCarnival template/icon
material. No author attribution or license authorizing redistribution of the
complete teaching content was established from its metadata, extracted page text,
embedded links or the targeted source search. Template provenance alone does not
establish permission to redistribute the full lesson. This is an unverified-rights
finding, not a determination that the document is unlawful.

The document is not referenced by application source or the bundled light-to-matter
lesson. Its removal changes neither that saved lesson nor its narration audio.
Users can supply their own authorized documents instead.

## Scope

This review concerns this particular PDF only. It is not a comprehensive rights
audit of every dependency, image, font or generated recording. Existing third-party
notices remain applicable. Previously published Git commits may still contain the
excluded file; this release removes it from the current tree and downloadable ZIP,
without rewriting repository history.
